8. Stripe Checkout Function

Nach Änderungen an Environment Variables die Function neu deployen.

Nach dem Deployment den generierten .appwrite.run-Link in site-config.js bei stripeCheckoutEndpoint eintragen.

9. Stripe Stock Webhook Function

Name: Chevalier Roth Stock Webhook
Runtime: Node.js 22
Code-Ordner: stripe-stock-webhook
Entrypoint: main.js
Build command: npm install
Execute access: Any

Scopes: rows.read + rows.write

Environment Variables:
STRIPE_SECRET_KEY
STRIPE_WEBHOOK_SECRET
Beide als Secret markieren.

In Stripe den generierten Webhook-Function-Link als Webhook Endpoint hinzufügen und nur das Event checkout.session.completed abonnieren.

Diese Function reduziert nach erfolgreicher Zahlung den Wert stock. Bei 0 zeigt die Website automatisch SOLD OUT.

1. Admin öffnen und einloggen.
2. Oben muss APPWRITE COMMERCE · CONNECTED erscheinen.
3. Wenn Products leer ist → IMPORT START PRODUCTS drücken.
4. Bei einem Produkt Stock z. B. auf 50 setzen → speichern → Seite auf anderem Gerät prüfen.
5. Rabattcode mit z. B. 15 % erstellen und direkt Produkte auswählen.
6. Gewinnspiel auf der Website öffnen, Test-Teilnahme absenden und im Admin → Giveaway prüfen.
7. Warteliste testweise ohne Login ausfüllen → Admin-Waitlist prüfen.
8. Stripe nur zuerst im Testmodus testen.
9. Nach einem Testkauf prüfen, ob Stock um die gekaufte Menge sinkt und der Order-Eintrag erscheint.
