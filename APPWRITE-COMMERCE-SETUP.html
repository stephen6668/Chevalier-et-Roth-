Appwrite Commerce Setup

One-time setup: create the three tables below in Database 6ac7d6740035408079f7 using the exact custom IDs. After that, product edits and stock are central for every device.

1. Products table

Table ID: cr_products

Permissions: Any → READ. Admin Team 6ac7d7fc0029522fc7bf → READ, CREATE, UPDATE, DELETE.

4. Stock automation

Deploy the included stripe-stock-webhook function and add its public domain as a Stripe webhook for checkout.session.completed. The function uses Appwrite atomic stock decrement with a minimum of zero. When the final unit is sold, the product stock becomes 0 and the website automatically shows SOLD OUT.
